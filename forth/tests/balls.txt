( BOUNCING BALLS IN COMP80 FORTH )\r
( BALLS RUNS SIX BALLS UNDER GRAVITY UNTIL A KEY IS PRESSED )\r
( TICK WAITS ABOUT 8 MS: IT HAS THE MM57109 PUT OUT A )\r
( NUMBER AND HALTS FOR EACH OF ITS 12 DIGITS, SO A KEY IS )\r
( TAKEN RATHER THAN RESETTING THE COMP80. IT LEAVES THE )\r
( LAST KEY PRESSED, OR 0; LETTERS COME AS 1-26. TICK IS )\r
( MACHINE CODE, PUT IN THE BODY OF A VARIABLE WHOSE CODE )\r
( THEN JUMPS TO IT. THE DIGITS GO IN KB )\r
HEX\r
VARIABLE KB A ALLOT  VARIABLE TICK 3E ALLOT  TICK CONSTANT T0\r
: M, ( A B -- A+1 ) OVER C! 1+ ;\r
: W, ( A W -- A+2 ) OVER ! 1+ 1+ ;\r
T0 C5 M, D5 M, ED M, 56 M, DB M, 3 M, E6 M, 20 M, 20 M,\r
FA M, 3E M, 16 M, D3 M, 60 M, 3E M, 96 M, D3 M, 60 M,\r
E M, 0 M, 21 M, KB W, 11 M, 803F W, AF M, FB M, 76 M,\r
F3 M, B7 M, 28 M, 1 M, 4F M, 7D M, FE M, KB C + FF AND M,\r
20 M, F0 M, DB M, 3 M, E6 M, 20 M, 20 M, FA M, 3E M, 3F M,\r
D3 M, 60 M, 3E M, BF M, D3 M, 60 M, 3E M, 20 M, 32 M,\r
803F W, D1 M, 6 M, 0 M, FD M, E9 M, DROP\r
T0 3 - C3 M, T0 SWAP ! DECIMAL\r
( SCREEN TABLES: * AND / ARE SLOW, SO A PIXEL'S CHARACTER )\r
( IS LOOKED UP: ROW Y GIVES THE ADDRESS OF ITS LINE, HALF X )\r
( ITS COLUMN )\r
HEX 8000 CONSTANT SCR DECIMAL\r
VARIABLE ROW 126 ALLOT  VARIABLE HALF 126 ALLOT\r
: TABLES ( -- ) 64 0 DO I 2 / 64 * SCR + I DUP + ROW + !\r
  LOOP 128 0 DO I 2 / I HALF + C! LOOP ;\r
TABLES\r
( FLIP XORS A CHARACTER'S QUARTERS: DRAWING TWICE RUBS OUT )\r
: FLIP ( MASK ADDR -- ) SWAP OVER C@ 15 AND XOR\r
  DUP IF 64 + ELSE DROP 32 THEN SWAP C! ;\r
( A BALL IS 2 BY 2 PIXELS: ONE CHARACTER, OR HALVES OF TWO, )\r
( OR QUARTERS OF FOUR, BY WHETHER X AND Y ARE ODD )\r
: BALL ( X Y -- ) OVER 1 AND OVER 1 AND >R >R\r
  DUP + ROW + @ SWAP HALF + C@ +  R> IF R> IF\r
  4 OVER FLIP 8 OVER 1+ FLIP 2 OVER 64 + FLIP 1 SWAP 65 +\r
  ELSE 6 OVER FLIP 9 SWAP 1+ THEN\r
  ELSE R> IF 12 OVER FLIP 3 SWAP 64 + ELSE 15 SWAP THEN\r
  THEN FLIP ;\r
6 CONSTANT N\r
( POSITIONS AND SPEEDS ARE IN 256THS OF A PIXEL )\r
VARIABLE BX 10 ALLOT  VARIABLE BY 10 ALLOT\r
VARIABLE VX 10 ALLOT  VARIABLE VY 10 ALLOT\r
: TH ( I A -- A ) SWAP DUP + + ;\r
VARIABLE SEED  VARIABLE SPEED  1 SPEED !\r
: RND ( N -- 0..N-1 ) SEED @ 31421 * 6927 + DUP SEED !\r
  128 / 255 AND * 256 / ;\r
: DRAW ( I -- ) DUP BX TH 1+ C@ SWAP BY TH 1+ C@ BALL ;\r
( AXIS ADDS V TO P, BOUNCING OFF LO AND HI )\r
VARIABLE PA  VARIABLE VA  VARIABLE LO  VARIABLE HI\r
: BACK ( -- ) VA @ DUP @ NEGATE SWAP ! ;\r
: AXIS ( PA VA LO HI -- ) HI ! LO ! VA ! PA !\r
  PA @ @ VA @ @ +\r
  DUP HI @ > IF HI @ DUP + SWAP - BACK THEN\r
  DUP LO @ < IF LO @ DUP + SWAP - BACK THEN  PA @ ! ;\r
( EACH STEP A BALL FALLS A LITTLE FASTER: GRAVITY )\r
: STEP ( I -- ) DUP DRAW  32 OVER VY TH +!\r
  DUP BX TH OVER VX TH 0 32255 AXIS\r
  DUP BY TH OVER VY TH 512 15871 AXIS  DRAW ;\r
: PAUSE ( -- K ) 0 SPEED @ 0 DO TICK OR LOOP ;\r
: START ( I -- ) 125 RND 256 * OVER BX TH !\r
  28 RND 256 * 512 + OVER BY TH !  64 RND 3 * 192 +  2 RND IF\r
  NEGATE THEN OVER VX TH !  64 RND 8 * 256 - OVER VY TH !\r
  DRAW ;\r
: BALLS ( -- ) PAGE  N 0 DO I START LOOP\r
  BEGIN N 0 DO I STEP LOOP PAUSE UNTIL PAGE ;\r
BALLS\r
