( TOWERS OF HANOI IN COMP80 FORTH, ANIMATED )\r
( N HANOI MOVES N DISCS FROM THE LEFT PEG TO THE RIGHT: )\r
( EACH DISC LIFTS OFF, SLIDES ACROSS AND DROPS ON AGAIN )\r
HEX 8000 CONSTANT SCR DECIMAL\r
28 CONSTANT FLOOR\r
VARIABLE TOP  VARIABLE LIFT  VARIABLE MOVES\r
VARIABLE SPEED  300 SPEED !\r
VARIABLE K  VARIABLE X  VARIABLE Y  VARIABLE DEST\r
VARIABLE HT 4 ALLOT\r
: HT@ ( P -- ADDR ) DUP + HT + ;\r
: PEG ( P -- X ) 21 * 11 + ;\r
: AT@ ( X Y -- ADDR ) 64 * + SCR + ;\r
( A PEG: RIGHT HALF OF ONE CHARACTER, LEFT HALF OF THE NEXT )\r
: POST ( X Y -- ) AT@ 70 OVER 1- C! 73 SWAP C! ;\r
( DISC K IS 2K LOWER HALF BLOCKS, CENTRED ON X )\r
: ROW ( C -- ) X @ K @ - Y @ AT@  K @ DUP + 0 DO\r
  OVER OVER I + C! LOOP DROP DROP ;\r
: SHOW ( -- ) 76 ROW ;\r
: HIDE ( -- ) 32 ROW  Y @ TOP @ < 0= IF X @ Y @ POST THEN ;\r
: WAIT ( -- ) SPEED @ 0 DO LOOP ;\r
: STEP ( DX DY -- ) HIDE Y +! X +! SHOW WAIT ;\r
: UP ( -- ) BEGIN Y @ LIFT @ > WHILE 0 -1 STEP REPEAT ;\r
: ACROSS ( X -- ) BEGIN DUP X @ - DUP WHILE\r
  0< IF -1 ELSE 1 THEN 0 STEP REPEAT DROP DROP ;\r
: DOWN ( Y -- ) BEGIN DUP Y @ > WHILE 0 1 STEP REPEAT DROP ;\r
: COUNT ( -- ) 1 MOVES +!  29 3 AT MOVES @ . ;\r
( MOVE DISC K, THE TOP ONE ON PEG FROM, ONTO PEG TO )\r
: MOVE ( K FROM TO -- ) DEST !  DUP PEG X !\r
  HT@ DUP @ FLOOR SWAP - Y !  -1 SWAP +!  K !\r
  UP  DEST @ PEG ACROSS\r
  DEST @ HT@ DUP @ 1+ DUP ROT !  FLOOR SWAP - DOWN  COUNT ;\r
( THE TWO PEGS GO ON THE STACK AS FROM * 3 + TO, )\r
( AND THE THIRD IS 3 - FROM - TO )\r
: SRC ( FT -- P ) 3 / ;\r
: DST ( FT -- P ) 3 MOD ;\r
: VIA ( FT -- P ) DUP SRC SWAP DST + 3 SWAP - ;\r
: TOVIA ( FT -- FT ) DUP SRC 3 * SWAP VIA + ;\r
: FROMVIA ( FT -- FT ) DUP VIA 3 * SWAP DST + ;\r
( N-1 DISCS OUT OF THE WAY, DISC N ACROSS, N-1 BACK ON TOP )\r
: HAN ( N FT -- ) OVER 0= IF DROP DROP EXIT THEN\r
  OVER 1- OVER TOVIA HAN\r
  OVER OVER DUP SRC SWAP DST MOVE\r
  OVER 1- OVER FROMVIA HAN  DROP DROP ;\r
: SETUP ( N -- ) PAGE  0 MOVES !\r
  21 1 AT ." TOWERS OF HANOI"  23 3 AT ." MOVES 0"\r
  FLOOR OVER - 1- DUP TOP !  2 - LIFT !\r
  64 0 DO 67 I FLOOR AT@ C! LOOP\r
  3 0 DO FLOOR TOP @ DO J PEG I POST LOOP LOOP\r
  DUP HT !  0 HT 2 + !  0 HT 4 + !  0 PEG X !\r
  DUP 0 DO DUP I - K !  FLOOR 1- I - Y !  SHOW LOOP DROP ;\r
: HANOI ( N -- ) DUP SETUP  2 HAN  0 30 AT ;\r
