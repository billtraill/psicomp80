( HILBERT CURVE IN COMP80 FORTH )\r
( A TURTLE DRAWS IT: EACH LEVEL IS FOUR CURVES OF THE LEVEL BELOW, )\r
( TURNED AND JOINED BY THREE STEPS.  LEVEL 5 IS 32 X 32 POINTS, )\r
( 4 CELLS APART ACROSS AND 2 DOWN, FOUR CELLS TO A CHARACTER )\r
HEX 8000 CONSTANT SCR DECIMAL\r
VARIABLE TITLE 62 ALLOT\r
VARIABLE X  VARIABLE Y  VARIABLE D\r
( THE BIT FOR EACH QUARTER OF A CHARACTER: TL TR BL BR )\r
VARIABLE BITS  1 BITS !  2 ,  8 ,  4 ,\r
( STEPS FOR EACH DIRECTION: EAST, SOUTH, WEST, NORTH )\r
VARIABLE DXS  1 DXS !  0 ,  0 1 - ,  0 ,\r
VARIABLE DYS  0 DYS !  1 ,  0 ,  0 1 - ,\r
: PLOT ( -- ) X @ 2 /  Y @ 2 / 64 * +  SCR +\r
  DUP C@ DUP 64 < IF DROP 64 THEN\r
  X @ 1 AND  Y @ 1 AND DUP +  +  DUP + BITS + @  OR  SWAP C! ;\r
: FD ( -- ) D @ 1 AND IF 2 ELSE 4 THEN 0 DO\r
  D @ DUP + DUP DXS + @ X +!  DYS + @ Y +!  PLOT LOOP ;\r
: TURN ( A -- ) D @ + 3 AND D ! ;\r
: HIL ( LEVEL A -- ) OVER 0= IF DROP DROP EXIT THEN\r
  DUP TURN  OVER 1- OVER NEGATE HIL  FD\r
  DUP NEGATE TURN  OVER 1- OVER HIL  FD\r
  OVER 1- OVER HIL  DUP NEGATE TURN  FD\r
  OVER 1- OVER NEGATE HIL  TURN DROP ;\r
( THE WHOLE SCREEN, TITLE LINE TOO; A KEY PUTS IT BACK )\r
