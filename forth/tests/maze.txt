( A MAZE IN COMP80 FORTH )\r
( MAZE CARVES A RANDOM MAZE OF 42 BY 29 ROOMS OUT OF A )\r
( SOLID SCREEN, THEN FINDS THE WAY FROM THE DOOR ON THE )\r
( LEFT TO THE DOOR ON THE RIGHT BY FILLING IN EVERY DEAD )\r
( END UNTIL ONLY THE WAY THROUGH IS LEFT.  A ROOM IS TWO )\r
( QUARTER CHARACTERS ACROSS AND ONE DOWN, WITH WALLS ONE )\r
( THICK, SO A STEP IS 3 ACROSS AND 2 DOWN AND COMES OUT )\r
( ABOUT SQUARE.  A KEY STARTS THE FILLING IN AND ANOTHER )\r
( CLEARS IT; MAZE AGAIN MAKES A NEW ONE )\r
HEX 8000 CONSTANT SCR DECIMAL\r
( SCREEN TABLES: * AND / ARE SLOW, SO A PIXEL'S CHARACTER )\r
( IS LOOKED UP: ROW Y GIVES ITS LINE, HALF X ITS COLUMN )\r
VARIABLE ROW 126 ALLOT  VARIABLE HALF 126 ALLOT\r
VARIABLE BIT 2 ALLOT\r
: TABLES ( -- ) 64 0 DO I 2 / 64 * SCR + I DUP + ROW + !\r
  LOOP 128 0 DO I 2 / I HALF + C! LOOP\r
  1 BIT C!  2 BIT 1+ C!  8 BIT 2 + C!  4 BIT 3 + C! ;\r
TABLES\r
: SPOT ( X Y -- ADDR MASK ) DUP 1 AND DUP + >R\r
  DUP + ROW + @ OVER HALF + C@ +\r
  SWAP 1 AND R> + BIT + C@ ;\r
: PIX? ( X Y -- F ) SPOT SWAP C@ AND ;\r
( DOT SETS A PIXEL WHEN PEN IS 1 AND CLEARS IT WHEN 0 )\r
VARIABLE PEN\r
: DOT ( X Y -- ) SPOT PEN @ IF OVER C@ OR ELSE -1 XOR\r
  OVER C@ AND THEN 15 AND DUP IF 64 + ELSE DROP 32 THEN\r
  SWAP C! ;\r
( RANDOM BYTES: THE TOP BYTE OF A 16-BIT LCG )\r
VARIABLE SEED\r
: RND8 ( -- 0-255 ) SEED @ 31421 * 6927 + SEED !\r
  SEED 1+ C@ ;\r
( DIRECTIONS 0-3 ARE RIGHT, DOWN, LEFT, UP )\r
VARIABLE DX  1 DX !  0 ,  -1 ,  0 ,\r
VARIABLE DY  0 DY !  1 ,  0 ,  -1 ,\r
: TH ( D TABLE -- ADDR ) SWAP DUP + + ;\r
( THE ROOM WE ARE IN, AND ITS LEFT PIXEL )\r
VARIABLE CI  VARIABLE CJ  VARIABLE PX  VARIABLE PY\r
: AT! ( -- ) CI @ DUP DUP + + 1+ PX !  CJ @ DUP + 5 + PY ! ;\r
: GO ( D -- ) DUP DX TH @ CI +!  DY TH @ CJ +!  AT! ;\r
: ROOM ( -- ) PX @ PY @ DOT  PX @ 1+ PY @ DOT ;\r
( THE WALL PIXEL ON SIDE D; WALL DRAWS THE WHOLE WALL )\r
: WXY ( D -- X Y ) DUP 1 AND IF 1 = IF 1 ELSE -1 THEN\r
  PY @ + PX @ SWAP ELSE 0= IF 2 ELSE -1 THEN PX @ +\r
  PY @ THEN ;\r
: WALL ( D -- ) DUP WXY OVER OVER DOT ROT 1 AND IF\r
  SWAP 1+ SWAP DOT ELSE DROP DROP THEN ;\r
( IS THE ROOM NEXT DOOR ON THE GRID AND STILL SOLID? )\r
: OK? ( N MAX -- F ) OVER > SWAP 0< 0= AND ;\r
: NEW? ( D -- F ) DUP DX TH @ CI @ +  SWAP DY TH @ CJ @ +\r
  OVER 42 OK? OVER 29 OK? AND IF DUP + 5 + SWAP DUP DUP\r
  + + 1+ SWAP PIX? ELSE DROP DROP 0 THEN ;\r
( A WAY TO A NEW ROOM, TRYING FROM A RANDOM SIDE, OR -1 )\r
: TRY ( -- D ) -1 RND8 3 AND  4 0 DO DUP I + 3 AND DUP\r
  NEW? IF ROT DROP SWAP ELSE DROP THEN LOOP DROP ;\r
( THE WAY BACK: ONE BYTE A STEP )\r
VARIABLE TOP  VARIABLE STK 1220 ALLOT\r
: PUSH ( D -- ) TOP @ C!  1 TOP +! ;\r
: POP ( -- D ) -1 TOP +!  TOP @ C@ ;\r
( CARVE: INTO A NEW ROOM IF THERE IS ONE, ELSE BACK A STEP )\r
: CARVE ( -- ) 0 PEN !  0 CI ! 0 CJ ! AT! ROOM  STK TOP !\r
  BEGIN TRY DUP 0< IF DROP TOP @ STK = IF EXIT THEN\r
  POP 2 + 3 AND GO ELSE DUP WALL DUP PUSH GO ROOM THEN\r
  AGAIN ;\r
( THE GAPS ROUND THIS ROOM, AND THE LAST ONE FOUND )\r
: OPEN? ( D -- F ) WXY PIX? 0= ;\r
: GAPS ( -- D N ) 0 0 4 0 DO I OPEN? IF SWAP DROP I SWAP\r
  1+ THEN LOOP ;\r
( A ROOM WITH ONE GAP IS A DEAD END: FILL IT AND ITS DOOR, )\r
( AND GO ON INTO THE NEXT ROOM, WHICH MAY BE ONE NOW )\r
: DEAD ( -- ) BEGIN GAPS 1 = WHILE ROOM DUP WALL GO REPEAT\r
  DROP ;\r
: SOLVE ( -- ) 1 PEN !  29 0 DO 42 0 DO I CI ! J CJ ! AT!\r
  DEAD LOOP LOOP ;\r
( A SOLID SCREEN BELOW THE TITLE, 127 BY 59 PIXELS )\r
: FILL ( -- ) 1984 128 DO 79 SCR I + C! LOOP\r
  2048 1984 DO 67 SCR I + C! LOOP\r
  31 2 DO 73 I 64 * 63 + SCR + C! LOOP  65 SCR 2047 + C! ;\r
: TITLE ( -- ) 0 1 AT ." MAZE: " ;\r
: MAZE ( -- ) PAGE TITLE ." CARVING" FILL  CARVE\r
  0 PEN !  0 5 DOT  126 61 DOT\r
  TITLE ." A KEY FINDS THE WAY THROUGH" KEY DROP\r
  TITLE ." FILLING IN THE DEAD ENDS   " SOLVE\r
  TITLE ." THE WAY THROUGH         " KEY DROP PAGE ;\r
