( ELEMENTARY CELLULAR AUTOMATA IN COMP80 FORTH )\r
( N RULE GROWS A ROW OF 128 CELLS FROM ONE LIVE CELL, ONE )\r
( GENERATION PER ROW OF QUARTER CHARACTERS DOWN THE SCREEN. )\r
( EACH CELL'S NEXT STATE IS BIT L*4+C*2+R OF N, WHERE L C R )\r
( ARE IT AND ITS NEIGHBOURS: TRY 30 RULE, 90 RULE, 110 RULE )\r
HEX 8000 CONSTANT SCR DECIMAL\r
( SCREEN TABLES: * AND / ARE SLOW, SO A PIXEL'S CHARACTER )\r
( IS LOOKED UP: ROW Y GIVES ITS LINE, HALF X ITS COLUMN )\r
VARIABLE ROW 126 ALLOT  VARIABLE HALF 126 ALLOT\r
VARIABLE BIT 2 ALLOT\r
: TABLES ( -- ) 64 0 DO I 2 / 64 * SCR + I DUP + ROW + !\r
  LOOP 128 0 DO I 2 / I HALF + C! LOOP\r
  1 BIT C!  2 BIT 1+ C!  8 BIT 2 + C!  4 BIT 3 + C! ;\r
TABLES\r
: SPOT ( X Y -- ADDR MASK ) DUP 1 AND DUP + >R\r
  DUP + ROW + @ OVER HALF + C@ +\r
  SWAP 1 AND R> + BIT + C@ ;\r
: PLOT ( X Y -- ) SPOT OVER C@ 15 AND OR 64 + SWAP C! ;\r
( RT HOLDS THE 8 BITS OF THE RULE, ONE A BYTE )\r
VARIABLE RT 6 ALLOT\r
: TABLE ( N -- ) 1 8 0 DO OVER OVER AND 0= 0= 1 AND\r
  I RT + C!  DUP + LOOP DROP DROP ;\r
( TWO ROWS OF CELLS, 1-128, WITH A DEAD CELL AT EACH END )\r
VARIABLE CA 128 ALLOT  VARIABLE CB 128 ALLOT\r
VARIABLE OLD  VARIABLE NEW  VARIABLE YY\r
: CLEAR ( A -- ) 130 0 DO 0 OVER I + C! LOOP DROP ;\r
( THE THREE CELLS SLIDE ALONG AS ONE NUMBER, 0-7 )\r
: GEN ( -- ) OLD @ DUP C@ DUP + SWAP 1+ C@ +\r
  128 0 DO DUP + 7 AND OLD @ I + 2 + C@ +\r
  DUP RT + C@ DUP NEW @ I + 1+ C!\r
  IF I YY @ PLOT THEN LOOP DROP ;\r
: FLIP ( -- ) OLD @ NEW @ OLD ! NEW ! ;\r
( A KEY CLEARS IT )\r
: RULE ( N -- ) DUP TABLE PAGE  0 1 AT\r
  ." ELEMENTARY CELLULAR AUTOMATON, RULE " .\r
  CA CLEAR CB CLEAR  CA OLD ! CB NEW !\r
  1 CA 65 + C!  64 4 PLOT\r
  64 5 DO I YY ! GEN FLIP LOOP KEY DROP PAGE ;\r
