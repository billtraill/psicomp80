( SNAKE IN COMP80 FORTH )\r
( SNAKE PLAYS: W A S D STEER, Q STOPS. EAT THE DOTS TO GROW; )\r
( DON'T HIT THE WALL OR YOURSELF )\r
( TICK WAITS ABOUT 8 MS: IT HAS THE MM57109 PUT OUT A )\r
( NUMBER AND HALTS FOR EACH OF ITS 12 DIGITS, SO A KEY IS )\r
( TAKEN RATHER THAN RESETTING THE COMP80. IT LEAVES THE )\r
( LAST KEY PRESSED, OR 0; LETTERS COME AS 1-26. TICK IS )\r
( MACHINE CODE, PUT IN THE BODY OF A VARIABLE WHOSE CODE )\r
( THEN JUMPS TO IT. THE DIGITS GO IN KB )\r
HEX\r
VARIABLE KB A ALLOT  VARIABLE TICK 3E ALLOT  TICK CONSTANT T0\r
: M, ( A B -- A+1 ) OVER C! 1+ ;\r
: W, ( A W -- A+2 ) OVER ! 1+ 1+ ;\r
T0 C5 M, D5 M, ED M, 56 M, DB M, 3 M, E6 M, 20 M, 20 M,\r
FA M, 3E M, 16 M, D3 M, 60 M, 3E M, 96 M, D3 M, 60 M,\r
E M, 0 M, 21 M, KB W, 11 M, 803F W, AF M, FB M, 76 M,\r
F3 M, B7 M, 28 M, 1 M, 4F M, 7D M, FE M, KB C + FF AND M,\r
20 M, F0 M, DB M, 3 M, E6 M, 20 M, 20 M, FA M, 3E M, 3F M,\r
D3 M, 60 M, 3E M, BF M, D3 M, 60 M, 3E M, 20 M, 32 M,\r
803F W, D1 M, 6 M, 0 M, FD M, E9 M, DROP\r
T0 3 - C3 M, T0 SWAP ! DECIMAL\r
( THE FIELD IS IN HALF CHARACTERS, ABOUT SQUARE: X 0-63, )\r
( Y 4-63. ROW Y GIVES THE ADDRESS OF ITS LINE )\r
HEX 8000 CONSTANT SCR DECIMAL\r
VARIABLE ROW 126 ALLOT\r
: TABLE ( -- ) 64 0 DO I 2 / 64 * SCR + I DUP + ROW + ! LOOP ;\r
TABLE\r
: AT@ ( X Y -- A ) DUP + ROW + @ + ;\r
( THE QUARTERS OF A CHARACTER THAT ARE ITS TOP OR BOTTOM )\r
: HM ( Y -- M ) 1 AND IF 12 ELSE 3 THEN ;\r
( WHAT IS AT X Y: 0 EMPTY, BOTH QUARTERS SNAKE OR WALL, )\r
( ONE QUARTER FOOD )\r
: LOOK ( X Y -- Q ) DUP HM >R AT@ C@ 15 AND R> AND ;\r
: PUT ( X Y P -- ) >R DUP HM R> AND >R AT@ DUP C@ 15 AND\r
  R> OR 64 + SWAP C! ;\r
: WIPE ( X Y -- ) DUP HM 15 XOR >R AT@ DUP C@ 15 AND R> AND\r
  DUP IF 64 + ELSE DROP 32 THEN SWAP C! ;\r
VARIABLE SEED\r
: RND ( N -- 0..N-1 ) SEED @ 31421 * 6927 + DUP SEED !\r
  128 / 255 AND * 256 / ;\r
( THE SNAKE: HEAD AT HX HY GOING DX DY. BODY HOLDS WHERE )\r
( IT HAS BEEN, A BYTE FOR X AND ONE FOR Y, FROM TAIL TO HEAD )\r
VARIABLE HX  VARIABLE HY  VARIABLE DX  VARIABLE DY\r
VARIABLE NDX  VARIABLE NDY  VARIABLE HEAD  VARIABLE TAIL\r
VARIABLE GROW  VARIABLE SCORE  VARIABLE SPEED  VARIABLE QUIT\r
VARIABLE BODY 1022 ALLOT\r
: HEADON ( -- ) HEAD @ DUP + BODY + HX @ OVER C! HY @ SWAP\r
  1+ C!  HEAD @ 1+ 511 AND HEAD ! ;\r
: TAILOFF ( -- ) TAIL @ DUP + BODY + DUP C@ SWAP 1+ C@ WIPE\r
  TAIL @ 1+ 511 AND TAIL ! ;\r
: MSG ( -- ) 14 1 AT ;\r
: SHOW ( -- ) 7 1 AT SCORE @ . ;\r
: FOOD ( -- ) BEGIN 62 RND 1+ 58 RND 5 + OVER OVER LOOK\r
  WHILE DROP DROP REPEAT 9 PUT ;\r
( EACH DOT IS WORTH A POINT AND THREE MORE PIECES OF SNAKE; )\r
( EVERY FOURTH ONE, THE SNAKE GOES FASTER )\r
: EAT ( -- ) 1 SCORE +!  SHOW  3 GROW +!  SCORE @ 4 MOD 0=\r
  SPEED @ 3 > AND IF -1 SPEED +! THEN  FOOD ;\r
: AHEAD ( -- X Y ) HX @ DX @ + HY @ DY @ + ;\r
( MOVE ONE PLACE ON; FALSE IF THE SNAKE HIT SOMETHING )\r
: MOVE ( -- F ) GROW @ IF -1 GROW +! ELSE TAILOFF THEN\r
  AHEAD LOOK DUP IF AHEAD SWAP DROP HM = IF 0 EXIT THEN\r
  -1 THEN  AHEAD HY ! HX !  HX @ HY @ 15 PUT  HEADON\r
  IF EAT THEN -1 ;\r
( A KEY: TURN, UNLESS IT WOULD GO BACK ON ITSELF )\r
: TURN ( DX DY -- ) OVER DX @ + 0= OVER DY @ + 0= AND\r
  IF DROP DROP ELSE NDY ! NDX ! THEN ;\r
: UPPER ( K -- C ) DUP 32 < IF 64 + THEN ;\r
: STEER ( K -- ) UPPER  DUP 87 = IF 0 -1 TURN THEN\r
  DUP 65 = IF -1 0 TURN THEN  DUP 83 = IF 0 1 TURN THEN\r
  DUP 68 = IF 1 0 TURN THEN  81 = IF -1 QUIT ! THEN ;\r
( WAIT FOR A KEY, STIRRING THE RANDOM NUMBERS MEANWHILE )\r
: WAITKEY ( -- K ) BEGIN 1 SEED +! TICK DUP 0= WHILE DROP\r
  REPEAT ;\r
: WALLS ( -- ) 64 0 DO I 4 15 PUT I 63 15 PUT LOOP\r
  63 5 DO 0 I 15 PUT 63 I 15 PUT LOOP ;\r
: SETUP ( -- ) PAGE 1 1 AT ." SCORE 0"  WALLS\r
  0 HEAD !  0 TAIL !  0 GROW !  0 SCORE !  0 QUIT !\r
  8 SPEED !  1 DX !  0 DY !  1 NDX !  0 NDY !  33 HY !\r
  4 0 DO 28 I + HX !  HX @ HY @ 15 PUT  HEADON LOOP  FOOD\r
  MSG ." PRESS A KEY TO START                   "\r
  WAITKEY STEER\r
  MSG ." W A S D STEER, Q STOPS                 " ;\r
( EACH STEP WAITS SPEED TICKS, TAKING KEYS AS THEY COME )\r
: FRAME ( -- ) SPEED @ 0 DO TICK DUP IF STEER ELSE DROP THEN\r
  LOOP ;\r
( ONE GAME, UNTIL THE SNAKE HITS SOMETHING OR Q IS PRESSED )\r
: PLAY ( -- ) SETUP  BEGIN FRAME  NDX @ DX !  NDY @ DY !\r
  QUIT @ IF -1 ELSE MOVE 0= THEN UNTIL ;\r
: AGAIN? ( -- F )\r
  MSG ." GAME OVER: ANY KEY PLAYS AGAIN, Q STOPS"\r
  WAITKEY UPPER 81 = 0= ;\r
: SNAKE ( -- ) BEGIN PLAY  QUIT @ IF 0 ELSE AGAIN? THEN 0=\r
  UNTIL PAGE ;\r
SNAKE\r
