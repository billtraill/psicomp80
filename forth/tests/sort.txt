( SORTING, TO WATCH, IN COMP80 FORTH )\r
( SORTS DRAWS 64 RANDOM BARS AND SORTS THEM WITH A BUBBLE )\r
( SORT, THEN THE SAME BARS WITH QUICKSORT, COUNTING THE )\r
( COMPARISONS AND SWAPS OF EACH.  A KEY AT THE END CLEARS )\r
HEX 8000 CONSTANT SCR DECIMAL\r
( BAR C IS COLUMN C, UP TO 60 HALF LINES TALL FROM LINE 31; )\r
( CELL K OF IT IS ON LINE 31 - K.  RA HOLDS THEIR ADDRESSES )\r
VARIABLE RA 58 ALLOT\r
: TABLE ( -- ) 30 0 DO SCR 1984 + I 64 * - I DUP + RA + !\r
  LOOP ;\r
TABLE\r
( CELL K OF A BAR H HALF LINES TALL: FULL, BOTTOM HALF, NONE )\r
: CELL ( H K -- B ) DUP + 1+ OVER OVER > IF DROP DROP 79\r
  ELSE = IF 76 ELSE 32 THEN THEN ;\r
( A BAR GOING FROM ONE HEIGHT TO ANOTHER: ONLY THE CELLS )\r
( BETWEEN THE TWO CHANGE )\r
VARIABLE BC  VARIABLE BH  VARIABLE LO  VARIABLE HI\r
: BAR ( C OLD NEW -- ) DUP BH !  OVER OVER > IF SWAP THEN\r
  1+ 2 / HI !  2 / LO !  BC !  LO @ BEGIN DUP HI @ < WHILE\r
  BH @ OVER CELL OVER DUP + RA + @ BC @ + C! 1+ REPEAT DROP ;\r
VARIABLE V 126 ALLOT\r
: V@ ( I -- X ) DUP + V + @ ;\r
: V! ( X I -- ) DUP + V + ! ;\r
VARIABLE COL  VARIABLE CMP  VARIABLE SWP\r
: COUNTS ( -- ) COL @ 11 + 1 AT CMP @ .\r
  COL @ 21 + 1 AT SWP @ . ;\r
( THE COUNTS GO ON LINE 1, FROM COLUMN COL; THE NAME AFTER )\r
: LABEL ( COL -- ) DUP COL !  0 CMP !  0 SWP !  7 + 1 AT\r
  ." CMP"  COL @ 17 + 1 AT ." SWP"  COUNTS  COL @ 1 AT ;\r
( SWAP BARS I AND J, REDRAWING BOTH )\r
VARIABLE XI  VARIABLE XJ\r
: XCH ( I J -- ) OVER V@ XI !  DUP V@ XJ !  XI @ OVER V!\r
  XJ @ ROT DUP >R V!  XJ @ XI @ BAR  R> XI @ XJ @ BAR\r
  1 SWP +!  COUNTS ;\r
( IS BAR I TALLER THAN BAR J? )\r
: BIGGER ( I J -- F ) 1 CMP +!  V@ SWAP V@ < ;\r
VARIABLE SEED\r
: RND ( N -- 0..N-1 ) SEED @ 31421 * 6927 + DUP SEED !\r
  128 / 255 AND * 256 / ;\r
( THE SAME 64 BARS EACH TIME: THE SEED STARTS THE SAME )\r
: FILL ( -- ) 1979 SEED !  64 0 DO I V@ 60 RND 1+ DUP I V!\r
  I ROT ROT BAR LOOP ;\r
: CLEAR ( -- ) 64 0 DO I I V@ 0 BAR  0 I V! LOOP ;\r
( BUBBLE SORT: EACH PASS CARRIES THE BIGGEST BAR LEFT TO THE )\r
( END, SO THE NEXT PASS IS ONE SHORTER )\r
: BUBBLE ( -- ) 0 LABEL ." BUBBLE"  63 0 DO 63 I - 0 DO\r
  I I 1+ BIGGER IF I I 1+ XCH THEN LOOP COUNTS LOOP ;\r
( QUICKSORT: THE BARS SMALLER THAN THE LAST ONE GO TO THE )\r
( LEFT, IT GOES NEXT TO THEM, AND EACH SIDE IS SORTED )\r
VARIABLE PIV  VARIABLE NX\r
: PART ( LO HI -- P ) DUP V@ PIV !  OVER NX !  DUP ROT DO\r
  1 CMP +!  I V@ PIV @ < IF NX @ I = 0= IF NX @ I XCH THEN\r
  1 NX +! THEN LOOP  NX @ OVER = 0= IF NX @ OVER XCH THEN\r
  DROP NX @ ;\r
: QS ( LO HI -- ) OVER OVER < 0= IF DROP DROP EXIT THEN\r
  OVER OVER PART ROT OVER 1- QS 1+ SWAP QS ;\r
: QUICK ( -- ) 33 LABEL ." QUICK"  0 63 QS  COUNTS ;\r
: PAUSE ( -- ) 30000 0 DO LOOP ;\r
: SORTS ( -- ) PAGE  V 128 + V DO 0 I ! 2 +LOOP\r
  FILL PAUSE BUBBLE  PAUSE CLEAR FILL PAUSE QUICK\r
  KEY DROP PAGE ;\r
SORTS\r
