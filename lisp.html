COMP80 LISP

A small LISP for the PSI COMP80, the Z80 computer published in Wireless World in 1979. It replaces BURP, the calculator program in the top 2 KB of the 3 KB ROM, and leaves the monitor alone, the same way COMP80 FORTH does. It is not a period ROM: it was written for the emulator, to see how much LISP fits in the space BURP had.

The answer is a LISP 1.5 style interpreter with garbage collection, recursion, LAMBDA and dynamic scope, enough to run the classic programs below. Every picture is a screenshot from the emulator, of a program typed in at the keyboard.

  • 2 KB of Z80 code, 0400–0BFF
  • 30 built-in functions and forms
  • 672 cells, or 7680 with the 32 KB expansion
  • 15-bit integers

A session

The emulator offers the ROM as a BIOS option, -bios lisp. Press RS at READY, as you would for BURP, and the top line changes to LISP. Type an expression and press Return; LISP prints its value. An expression can run over several lines, since LISP keeps reading until the brackets balance.

  • ^ rub out (Backspace in MAME)
  • Return end the line
  • any key: stop a running program, back to READY
  • ^ at READY: back to LISP, functions kept

The language

Symbols are names; numbers are integers from −16384 to 16383. NIL is the empty list and false, and anything else is true. A function is a value like any other: (DEFUN SQ (X) (* X X)) sets SQ to the list (LAMBDA (X) (* X X)), and (F 3) calls whatever F holds.

OtherEVAL, GC (collect garbage, return the free cells)
  • Variables are dynamically scoped, as in the original LISP: a function sees the variables of whatever called it, unless it has a parameter of the same name. The eight queens program uses this.
  • Bodies of LAMBDA, DEFUN and COND clauses can hold several expressions; the last one gives the value. Missing arguments are NIL.
  • (TYO 143) prints a solid block: codes 128 to 191 are the COMP80’s graphics characters. ; starts a comment.
  • An error prints a message and the culprit (UNBOUND FOO, BAD FN 1, BAD ARG A, TOO DEEP, NO MEM), abandons the expression and puts every variable back as it was.
  • Left out to fit in 2 KB: IF, LET, PROG, strings, RPLACA, APPLY, typing in dotted pairs, and floating point. APPEND, REVERSE, MAPCAR and EQUAL are a few lines of LISP each.

Symbolic differentiation

McCarthy designed LISP for symbolic work like this: an expression is a list, so a program can take it apart and build a new one. DERIV applies the sum, product and power rules; S+, S* and the others build the answer and tidy it as they go, so (* 1 X) becomes X and (+ 3 3) becomes 6. The last example differentiates twice.

The program, lisp/examples/deriv.lsp
; Symbolic differentiation, the classic LISP program.
; (DERIV E X) is the derivative of E with respect to X, where
; E is built from numbers, symbols, (+ A B), (- A B), (* A B)
; and (EXPT A N).  S+ S- S* and SEXPT build a result,
; simplifying as they go.
(DEFUN DERIV (E X)
  (COND ((ATOM E) (COND ((EQ E X) 1) (T 0)))
        ((EQ (CAR E) '+)
         (S+ (DERIV (CADR E) X) (DERIV (CADDR E) X)))
        ((EQ (CAR E) '-)
         (S- (DERIV (CADR E) X) (DERIV (CADDR E) X)))
        ((EQ (CAR E) '*)
         (S+ (S* (CADR E) (DERIV (CADDR E) X))
             (S* (DERIV (CADR E) X) (CADDR E))))
        ((EQ (CAR E) 'EXPT)
         (S* (S* (CADDR E) (SEXPT (CADR E) (- (CADDR E) 1)))
             (DERIV (CADR E) X)))))
(DEFUN S+ (A B)
  (COND ((EQ A 0) B)
        ((EQ B 0) A)
        ((AND (NUMBERP A) (NUMBERP B)) (+ A B))
        ((EQUAL A B) (S* 2 A))
        (T (LIST '+ A B))))
(DEFUN S- (A B)
  (COND ((EQ B 0) A)
        ((AND (NUMBERP A) (NUMBERP B)) (- A B))
        ((EQUAL A B) 0)
        (T (LIST '- A B))))
(DEFUN S* (A B)
  (COND ((EQ A 0) 0)
        ((EQ B 0) 0)
        ((EQ A 1) B)
        ((EQ B 1) A)
        ((NUMBERP B) (COND ((NUMBERP A) (* A B)) (T (S* B A))))
        ((AND (NUMBERP A) (NULL (ATOM B)) (EQ (CAR B) '*)
              (NUMBERP (CADR B)))
         (S* (* A (CADR B)) (CADDR B)))
        (T (LIST '* A B))))
(DEFUN SEXPT (A N)
  (COND ((EQ N 0) 1) ((EQ N 1) A) (T (LIST 'EXPT A N))))
(DEFUN EQUAL (A B)
  (COND ((ATOM A) (EQ A B))
        ((ATOM B) NIL)
        ((EQUAL (CAR A) (CAR B)) (EQUAL (CDR A) (CDR B)))))

Towers of Hanoi

Move a pile of discs from one peg to another, one disc at a time, never putting a bigger disc on a smaller one. The recursive answer is three lines: move all but the bottom disc out of the way, move the bottom disc, then move the rest back on top. Four discs take 15 moves.

The program, lisp/examples/hanoi.lsp
; The Towers of Hanoi: move N discs from peg FROM to peg TO,
; using peg VIA, one disc at a time and never a bigger disc
; on a smaller one.
(DEFUN HANOI (N FROM TO VIA)
  (COND ((EQ N 0) NIL)
        (T (HANOI (- N 1) FROM VIA TO)
           (PRINT (LIST 'MOVE 'DISC N 'FROM FROM 'TO TO))
           (HANOI (- N 1) VIA TO FROM))))

Eight queens

Place eight queens on a chessboard so that none attacks another. TRY puts a queen in the first safe row of the next column and backs up when a column has none. Finding the first answer takes 114 placements, 2,318 safety checks and about 26 s in the emulator. N is never passed to PLACE, TRY or ROW: dynamic scope finds the N that QUEENS was called with.

The program, lisp/examples/queens.lsp
; The eight queens: put N queens on an N x N board with no two
; in the same row, column or diagonal.  A board is the list of
; the queens' rows, the newest column first.  N is a free
; variable in PLACE, TRY and ROW: LISP's dynamic scope finds
; QUEENS's N.
(DEFUN OK (R QS D)
  (COND ((NULL QS) T)
        ((EQ R (CAR QS)) NIL)
        ((EQ (- R (CAR QS)) D) NIL)
        ((EQ (- (CAR QS) R) D) NIL)
        (T (OK R (CDR QS) (+ D 1)))))
(DEFUN PLACE (QS K)
  (COND ((EQ K N) QS) (T (TRY 1 QS K))))
(DEFUN TRY (R QS K)
  (COND ((> R N) NIL)
        (T (OR (AND (OK R QS 1) (PLACE (CONS R QS) (+ K 1)))
               (TRY (+ R 1) QS K)))))
(DEFUN ROW (C Q)
  (COND ((> C N) (TERPRI))
        (T (TYO (COND ((EQ C Q) 81) (T 46)))
           (TYO 32)
           (ROW (+ C 1) Q))))
(DEFUN SHOW (B)
  (COND (B (ROW 1 (CAR B)) (SHOW (CDR B)))))
(DEFUN QUEENS (N)
  ((LAMBDA (B) (SHOW B) B) (PLACE NIL 0)))

Inside

Every object is a 16-bit word, and the value says what it is. NIL is 0. A number n is stored as 2n + 1, so numbers are the odd words. A symbol is the address of its record in the symbol table: its value, then its name. A cell is the address of four bytes in the heap, the car and then the cdr, and every even word from 1000h up is a cell. A built-in function is a small even number that indexes a table of machine code addresses. The symbol table starts as a copy of the built-in names, each holding its built-in as its value, which is why CAR evaluates to the function that (CAR X) calls.

Calling a LAMBDA evaluates the arguments into a list, saves the parameters’ old values on a binding stack, stores the new values straight into the symbols, evaluates the body and puts the old values back. That is shallow binding, which makes reading a variable a single memory fetch. An error or a key press unwinds the binding stack the same way.

Garbage collection is mark and sweep, with one mark bit per cell in a bitmap. It starts from the symbol table, the binding stack and the Z80 stack. The Z80 stack is scanned conservatively, keeping any word on it that could be a cell, so the machine code only has to keep what it still needs on the stack when it asks for a new cell.

AddressUse

0400–0BFFLISP, where BURP was. The two words at 06B4 that Game of Life borrows are kept, and RS still enters at 0800.

The basic machine holds one of the example programs at a time: DERIV takes about 380 of the 672 cells and the queens about 190. Everything lives in RAM, so stopping a program and pressing RS at READY brings LISP back with your functions intact.

The source is lisp/lisp.asm; lisp/build.sh assembles it with z80asm into psicomp80_lisp.rom, and lisp/README.md has the full reference, the tests and how the screenshots are made.

lisp/build.sh && mame/install.sh      # then rebuild MAME
cd ~/localdev/mame && ./mamed psicomp80 -bios lisp
Screens are 384 × 320 dots, shown stretched to 4:3 the way a 1979 television would show them. Times are emulated machine time. The other screens and the FORTH ROM are on PSI COMP80 Screens.
