Wireless World, 1979–80 · running in MAME

PSI COMP80 Screens

The PSI COMP80 was a Z80 computer designed by J. H. Adams and published as a build-it-yourself series, “A scientific computer”, in Wireless World. The six parts ran monthly from April to September 1979. Two follow-up articles on the monitors appeared in January and February 1980, and a two-part floppy disc extension in October and December 1980.

This MAME driver runs the computer’s 3 KB monitor ROM, typed back in from the magazine’s hex listing. Every picture below is a screenshot from the emulator, and every program loads from a cassette tape image or the floppy disc.

  • Z80 at 2 MHz
  • 64 × 32 characters, 6 × 10 dots each
  • 5 KB RAM from 0C00
  • Tape 300 baud, 1200 / 2400 Hz

The kit

Powertran sold the computer as a kit. The leaflet calls it the “PSI COMP 80, Z80 based computer” and shows the finished machine: a keyboard with a separate hex keypad, READY and DATA IN lamps, and a television as the display.

The kit in these photos, still in its box with the leaflet, drawings, case and bagged parts, was offered for sale on eBay.

Starting a program

c80.sh starts the emulator straight into a program: it puts the program in memory and types the command for you. The command under each screen starts it. Add MAME options after the name, for example -nowindow for full screen.

~/localdev/psicomp80/c80.sh life      # or boat, schmitt, alph, list, disk, ready

To load from the cassette image the way the real machine would, use the tape commands further down.

The monitor

Commands are a word, a space and hex addresses. A command runs as soon as its last digit is typed, with no Return.

Game of Life

Conway’s Life on a 128 × 64 board that wraps at the edges. Each character cell shows four cells using the quadrant block graphics. Written in Z80 assembly; about 0.65 s per generation in the emulator.

  • R new random board
  • P pause / resume
  • S stop, back to the monitor
Or load it from tape
cd ~/localdev/mame && ./mamed psicomp80 -cass ~/localdev/psicomp80/life/life.wav -autoboot_script ~/localdev/psicomp80/autorun.lua

Floppy disc

The disc extension from Wireless World, October and December 1980: an FD1771 controller and an 8in drive holding about 250 KB in the IBM 3740 format. The disc software from the December article is typed in at 1D00. The program disc holds everything above. FORMAT needs the 32 KB memory expansion, so it runs on the second machine, started with c80.sh 32k disk.

Or load it from tape
cd ~/localdev/mame && C80_ADDR=1D00 ./mamed psicomp80 -cass ~/localdev/psicomp80/disk/fdos.wav -flop ~/localdev/psicomp80/disk/programs.img -autoboot_script ~/localdev/psicomp80/autorun.lua
Screens are 384 × 320 dots, shown stretched to 4:3 the way a 1979 television would show them. Tape images live in the psicomp80 repository next to their source.
